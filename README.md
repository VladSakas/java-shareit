# ShareIt API (В разработке)

REST API для шеринга вещей. Пользователи могут добавлять вещи в аренду, искать их и управлять своими вещами.

## Запуск

Запустите `ru.practicum.shareit.ShareItApplication`

Сервер стартует на `http://localhost:8080`

## Эндпоинты

### Пользователи (Users)

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/users` | все пользователи |
| GET | `/users/{id}` | пользователь по ID |
| POST | `/users` | создать пользователя |
| PATCH | `/users/{id}` | обновить пользователя |
| DELETE | `/users/{id}` | удалить пользователя |

### Вещи (Items)

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/items` | все вещи пользователя |
| GET | `/items/{itemId}` | вещь по ID |
| POST | `/items` | добавить вещь |
| PATCH | `/items/{itemId}` | обновить вещь (только владелец) |
| DELETE | `/items/{itemId}` | удалить вещь (только владелец) |
| GET | `/items/search?text={text}` | поиск вещей (только доступные) |
